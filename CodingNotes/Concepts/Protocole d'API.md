Une **API** est un ensemble de règles et de protocoles qui définissent comment 2 logiciels vont échanger. Un sorte de contrat qui dit : on appelle avec le format X, répond avec format Y, les routes sont définies sous format Z.

API REST utilise des requêtes HTTP sous format JSON en général.
API REST doit être : 
Stateless : un appel ne doit dépendre d'un autre
Utilise les verbes HTTP
Les données sont exposés dans les routes et on utilise les verbes HTTP CRUD pour définir l'action.
